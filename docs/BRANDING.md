# Epistemic AI identity

Diffstory is an Epistemic AI open-source project. The reader uses the current Epistemic AI application palette and the supplied first-party symbol, with a restrained text endorsement rather than another navigation layer.

| Token | Value | Purpose |
|---|---|---|
| Accent | `#2563eb` | Links, mark, progress, focus |
| Ink | `#0f172a` | Headings and primary text |
| Body | `#475569` | Narrative and secondary content |
| Muted | `#64748b` | Metadata |
| Border | `#e2e8f0` | Rules and code boundaries |
| Paper | `#ffffff` | Reading surface |
| Code surface | `#f8fafc` | Source background |

These values and the mark were checked against Epistemic AI's current application assets on September 24, 2026. Additional green/red diff tones express additions and deletions, not corporate branding.

Prose uses system Georgia with serif fallbacks; controls use the system sans-serif stack; code uses the system monospace stack. No downloadable fonts or external assets are required.

## Logo and trademarks

`diffstory/assets/epistemic-mark.svg` identifies Epistemic AI. Retain proportions, clear space, and legibility. It may accompany copies of this project to identify the original publisher. The software's MIT license does not transfer trademark rights or permit a fork to imply it is the official Epistemic AI product.

A fork may replace the mark and attribution styling in the template without changing the compiler. Keep copyright/license notices in the distribution. No broader corporate brand guidelines are implied by this project-specific styling guide.
