# Public release provenance

The application source derives from the latest single-page Diffstory prototype. The original prototype's private demonstration files, embedded source excerpts, generated reports, screenshots, and build outputs were excluded from this release tree. No original Git history is carried into the publication bundle.

`examples/make_demo.py` contains newly authored, synthetic before/after source for a small catalog-search refactor. It performs no network requests and reads no external repository. Its revision identifiers are deterministic SHA-1 hashes of the synthetic source dictionaries, not claims about real Git commits. The reader labels the example accordingly and creates no fictional GitHub source links.

The generated snapshot, annotations, report, and HTML are reproducible from that script. Annotations are authored explanations tied to the compiler's evidence IDs. The compiler's `test_runs` stays zero, even when test source is present.

Epistemic AI's mark is a separately identified first-party brand asset. No private application logic is imported or required. Screenshots are freshly rendered from the public synthetic example.
